# 3D 地铁站客流仿真系统

基于 Vue 3、TypeScript、Three.js 和 Vite 的地铁站客流仿真 Demo。

## 功能

- 双层站厅、两处侧式站台、轨道、列车、6 个闸机、扶梯和楼梯场景。
- 乘客从 3 个入口随机生成，自动通过闸机前往不同站台。
- 列车按“进站—停靠开门—出站—循环”运行，支持乘客候车、上车、下车和出站。
- 基于图结构的 Dijkstra 寻路，并将局部拥堵计入路径代价。
- 可在 UI 或 3D 场景中临时关闭闸机、扶梯或楼梯，乘客会自动重新规划路线。
- InstancedMesh 实例化乘客和热力网格，用青色→黄色→红色展示实时拥堵区域。
- 可调节生成速率、客流上限、仿真倍速、暂停、复位和热力图显示。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

浏览器打开 Vite 输出的本地地址后，鼠标左键旋转、滚轮缩放、右键平移；点击闸机或通道封条可切换通行状态。
